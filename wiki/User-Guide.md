# User Guide

Complete guide for students using the Subodh Exam Portal.

## Getting Started

### Accessing the Portal

1. Open your web browser (Chrome, Firefox, Safari, or Edge)
2. Navigate to: [https://anacondy.github.io/25-2-saving-pro-2/](https://anacondy.github.io/25-2-saving-pro-2/)
3. The portal works on desktop, tablet, and mobile devices

## Features Overview

### 1. Search Papers

The main feature of the portal is the powerful search functionality.

#### How to Search

1. **Locate the Search Bar**
   - On the first card labeled "Paper Archive"
   - A white input box with placeholder text

2. **Enter Search Terms**
   - Subject name (e.g., "Physics", "History")
   - Paper code (e.g., "PHY-302", "HIS-101")
   - Keywords from paper title

3. **View Results**
   - Results appear instantly as you type
   - Each result shows:
     - Paper title
     - Paper code
     - Subject name
     - Category tag (Subsidiary, GEC, SEC)
     - Semester in crimson red

#### Search Tips

- **Be Specific**: "Quantum Mechanics" works better than just "Physics"
- **Use Codes**: Paper codes like "PHY-302" give exact matches
- **Partial Match**: Type part of the name, e.g., "Java" for "Java Programming"
- **Case Insensitive**: "physics" and "Physics" give same results

#### Understanding Results

Results are color-coded by category:

- **Blue Tags**: Subsidiary subjects (core subjects)
- **Purple Tags**: Generic Elective (GEC) and Skill Enhancement (SEC)
- **Green Tags**: Main semester exams
- **Red Semester Tags**: Semester number in bold crimson

### 2. Navigation

Navigate through different sections of the portal.

#### Desktop Navigation

**Arrow Keys**
- Press `→` (Right Arrow) to go to next section
- Press `←` (Left Arrow) to go to previous section

**Mouse**
- Click and drag the cards to scroll (coming soon)

#### Mobile Navigation

**Swipe Gestures**
- Swipe left to see next section
- Swipe right to see previous section

**Tap**
- Tap on cards to interact with content
- Tap buttons to perform actions

### 3. Sections Overview

The portal has 6 main sections:

#### Section 1: Paper Archive (Green Theme)
- **Purpose**: Search and find exam papers
- **Features**: Real-time search, categorized results
- **Use**: Main entry point for students

#### Section 2: Statistics (Purple Theme)
- **Purpose**: Statistical Inference papers
- **Features**: Browse specific subject papers
- **Use**: Quick access to Statistics resources

#### Section 3: Computer Applications (Blue Theme)
- **Purpose**: Programming and CS papers
- **Features**: Code examples, algorithm papers
- **Use**: Computer science students

#### Section 4: Notice Board (Orange Theme)
- **Purpose**: Important announcements
- **Features**: Exam schedules, datesheets
- **Use**: Stay updated on exam dates

#### Section 5: Admin Uploads (Red Theme)
- **Purpose**: Faculty upload section
- **Features**: Secure admin panel
- **Use**: Restricted to authorized users

#### Section 6: Contribution Log (Teal Theme)
- **Purpose**: Activity feed
- **Features**: Recent uploads and updates
- **Use**: Transparency and tracking

## Common Tasks

### Finding a Specific Paper

1. Go to Section 1 (Paper Archive)
2. Type paper code or subject name
3. Browse results
4. Click on desired paper to download

### Browsing by Subject

1. Navigate to the relevant subject section
2. Click "View Papers" button
3. Browse available papers
4. Download as needed

### Checking Exam Schedule

1. Navigate to Section 4 (Notice Board)
2. Click "Download PDF" button
3. View/download the datesheet

## Tips for Best Experience

### Performance Tips

1. **Use Latest Browser**: Chrome, Firefox, or Edge
2. **Clear Cache**: If portal seems slow

4. **Mobile Data**: Portal is lightweight, works on mobile data

4. **High Contrast**: Works with system high contrast mode

1. **Portrait Mode**: Optimized for portrait orientation

3. **Swipe Navigation**: Faster than tapping arrows
4. **Save to Home**: Add portal to home screen for quick access

## Troubleshooting

### Search Not Working

**Problem**: Search doesn't show results
**Solutions**:
1. Check spelling
2. Try different keywords
3. Use paper code instead of name
4. Refresh the page

### Can't Navigate

**Problem**: Arrow keys or swipe doesn't work
**Solutions**:
1. Make sure you're not in admin modal
2. Refresh the page
3. Try opposite direction first
4. Use browser back/forward buttons

### Page Not Loading

**Problem**: Portal doesn't load properly
**Solutions**:
1. Check internet connection
2. Try different browser
3. Clear browser cache
4. Disable ad blockers temporarily
5. Check if GitHub Pages is operational

### Papers Not Downloading

**Problem**: Can't download papers
**Solutions**:
1. Check browser download settings
2. Allow pop-ups from the site
3. Check available storage space
4. Try different browser

## FAQ

### Is the portal free to use?
Yes, completely free for all Subodh College students.

### Do I need to login?
No, students don't need to login. Search and download are open.

### How often are papers updated?
Papers are uploaded by faculty regularly. Check the Contribution Log for recent updates.

### Can I access old exam papers?
Yes, the archive includes papers from multiple years and sessions.

### Is mobile access available?
Yes, the portal is fully responsive and works great on mobile devices.

### Can I bookmark papers?
Currently, bookmarking is not available. Use browser bookmarks for now.

### What file format are papers in?
All papers are in PDF format for universal compatibility.

### Can I print papers?
Yes, download the PDF and print from your device.

### Is there a download limit?
No, download as many papers as you need.
