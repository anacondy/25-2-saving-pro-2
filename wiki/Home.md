## 🚀 Quick Start

### For Students
1. Visit the portal at [https://anacondy.github.io/25-2-saving-pro-2/](https://anacondy.github.io/25-2-saving-pro-2/)
2. Use the search bar to find papers by subject, code, or name
3. Navigate using arrow keys or swipe gestures
4. Download papers directly from search results

### For Admins
1. Type `upload` on the portal (secret code)
2. Enter admin credentials (username: `alvido`)
3. Fill in paper metadata
4. Upload PDF files (drag & drop or browse)
5. Submit to database

## 🎯 Key Features

### Search & Discovery
- Real-time search with instant results
- Color-coded categories (Subsidiary, GEC, SEC, etc.)
- Semester tags in crimson red
- Filter by subject, code, or paper name

### Modern UI/UX
- Glassmorphism design
- Smooth carousel navigation
- Responsive layout (mobile, tablet, desktop)
- Keyboard and touch gestures support
- Dynamic theme colors per section

### Security
- XSS protection with input sanitization
- Content Security Policy (CSP) headers
- File validation (type and size)
- Secure admin authentication
- No credential storage in browser

### Administration
- Batch and individual upload modes
- Comprehensive metadata form
- Drag & drop file upload
- Real-time validation
- Activity logging
